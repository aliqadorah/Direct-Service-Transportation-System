## Code review — summary (independent reviewer + author)
No tenant/company leak and no injection (JSON paths from validated keys, filter values typed and escaped). Report maths, saved-report visibility, expression trees and the dashboard's permission gates were checked and found sound.
- **Fixed:** B10-1 tariff breach is the customer price against the stored tariff (trips store no partner tariff); "partner" lists the breaches of partner trips (DT-119); B10-2 driver balances as of a past date count items settled later or by a void settlement as open; B10-3 a run period replaces the definition's filters on the main date; B10-4 drill-down links carry the report's filters, the period and date ranges per unit, flags as true/false; B10-5 grouping without a pivot reads at most 5,001 rows, measure ordering and top-N in SQL, truncation flagged for row and column caps; B10-7 standard-report periods capped at 10 years; B10-8 null definition elements → 400; B10-9 pins hide reports no longer visible and never fail the dashboard; B10-10 custom dates typed as dates; B10-11 "total (all rows)" label with top-N, count of a field counts values; B10-12 the numeric JSON function failed at runtime (nullable return type, missing type mapping) — fixed and covered by a test.
- **Decided:** B10-6 reports.view opens every standard report and the cash cards ("all reports", PRD 3.4) while builder sources keep their module permission (FR-147) — DT-117.
